🚀 Students API (/students)

Action	Method	URL	Notes
Get student by ID	GET	/api/students/:id	Fetch a single student
Get all students	GET	/api/students?page={n}	Supports pagination
Create student	POST	/api/students	Add a new student
Update student	PUT	/api/students/:id	Modify student details
Delete student	DELETE	/api/students/:id	Remove student
